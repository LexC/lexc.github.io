# Alex Carvalho — professional website

A lightweight professional portfolio built with **Lektor (Python)**, **Jinja2**, **Tailwind CSS v4**, and **Alpine.js**. The published result is static HTML/CSS/JS hosted on GitHub Pages.

## Local development

Requirements: Python 3.11+, Node.js 20+.

```bash
python -m venv .venv
# Activate .venv for your shell
python -m pip install -r requirements.txt
npm install --no-package-lock
npm run css:build
lektor server
```

During design iteration, run `npm run css:watch` separately.

## Production build

```bash
npm run css:build
lektor build --output-path dist
```

The GitHub Actions workflow builds and deploys `dist/` on merges to `main`, after GitHub Pages is configured to use **GitHub Actions** as the build source.

## Architecture

- `content/`: editable site copy, separated from presentation.
- `models/`: Lektor's content schema.
- `templates/`: Jinja2 layouts and reusable page components.
- `assets/css/input.css`: Tailwind entrypoint and custom visual system.
- `assets/css/site.css`: compiled CSS generated by npm (not committed).
- `assets/js/site.js`: tiny interaction layer; Alpine is loaded as a small progressive enhancement.
- `.github/workflows/pages.yml`: build and deploy pipeline.

### Editorial checklist before publication

- Replace the preliminary career copy with reviewed claims.
- Add real publication titles, links, and selected project descriptions.
- Add a verified résumé PDF before linking one.
- Supply an intentional contact method.
- Confirm site metadata, accessibility, mobile layout, and performance.

The design uses a white canvas, near-black typography, and a restrained scientific heatmap spectrum. Its visualization is purely decorative, not a chart of real data.
